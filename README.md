# 리눅스 데스크탑 (Linux Desktop Android) — 9.5.1

루팅이나 부트로더 언락 없이 PRoot 기반으로 10종 리눅스 배포판을 실행하고 내장 VNC 뷰어로 사용하는 Android 앱입니다.

## 주요 기능
- 10종 배포판 지원 (Ubuntu, Debian, Fedora, Arch, Alpine, Kali, openSUSE, Void, Manjaro, Rocky)
- 내장 RFB 3.8 VNC 뷰어, 가상 키보드·트랙패드
- 갤럭시 탭 키보드 북커버 / 프로 키보드 및 물리 트랙패드(스크롤·우클릭·포인터) 네이티브 지원
- One UI 9.5 리퀴드 글래스 UI 및 GitHub Releases 앱 내 업데이트
